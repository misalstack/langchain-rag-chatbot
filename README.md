## ✨ Features & Capabilities

* 🧠 **Simulated RAG Pipeline:** Visualizes 5-stage retrieval pipeline (`Query Analysis → Embed Query → Vector Retrieval → Re-rank Chunks → LLM Generation`).
* 🗄️ **Multi-Domain Knowledge Base:** Live switching across MiSal Stack Docs, Tech Stack Guide, and AI/ML Capabilities vector stores.
* 📊 **Real-time Pipeline Metrics:** Tracks active query counts, retrieved chunk totals, average latency, and semantic relevance scores dynamically.
* 💬 **Interactive Conversational UI:** Pre-built question suggestions with citation chips highlighting source documents and confidence scores.
